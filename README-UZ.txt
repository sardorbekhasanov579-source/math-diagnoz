MATH-DIAGNOZ v1.5 - BITTA MAKTAB UCHUN LAN PILOT
================================================
Avvalgi v1.4 bosh sahifa va kabinetlari saqlangan.

Eng muhim fayl: MAKTAB-ICHKI-TARMOQ-QOLLANMA.txt (batafsil qadamlar)
Windowsda: START-MAKTAB-SERVER.bat ni ikki marta bosing.
Agar eski bazangiz bo'lsa, oldin v1.4 ni MATH-DIAGNOZ-ESKI deb
nomlab, ESKI-BAZANI-KOCHIRISH.bat ni (serverlar toxtagan holda)

Maktab tarmogi uchun server: npm.cmd run build:school va npm.cmd run school
Maktab kirish manzili: http://SERVER-IP:4173/

hisoblarini faqat administrator yaratadi.
